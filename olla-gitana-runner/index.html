OLLA GITANA

LA HUERTA RUNNER 🥘🏃

La olla cruza Murcia a toda mecha: salta obstáculos, recoge ingredientes y llena la cazuela. Cada 500 puntos, escenario nuevo.

Toca la pantalla para saltar · mantén para saltar más alto · Hecho en Murcia

CÓMO SE JUEGA

  • Toca la pantalla (o ESPACIO/↑) para saltar. Mantén pulsado para saltar más alto.
  • Doble toque en el aire = doble salto. Desliza hacia abajo (o ↓) para agacharte.
  • Ingredientes 🍐🌿🧆🌶️🥘: súmalos todos, suben el combo (x1 → x5).
  • Obstáculos de suelo 🚧💊🧱: sáltalos.
  • Obstáculos aéreos 🚬💉🦟 (banda roja con flecha ⬇): agáchate para pasar por debajo. ¡Ojo, saltar no vale!
  • 3 vidas. Cada 500 puntos sube el nivel: +9% de velocidad y escenario nuevo (hasta x1.8).
  • Al chocar pierdes combo y ganas unos segundos de invulnerabilidad (parpadeas).
